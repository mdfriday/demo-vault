# Knowledge Management

Good KM is mostly **deletion and linking**.

## Rules that scale

| Rule | Why |
|------|-----|
| One idea per note | Easier links |
| Link outward twice | Graph stays alive |
| Rewrite when reused | Stale notes rot trust |

> [!note]
> Tags find clusters. Wikilinks build structure. Use both — don’t worship either.

## From private to public

Private notes become public assets when they’re clear enough for a stranger. That’s the bridge to a [[Digital Garden]] and to products like [[Share exactly what you see in Obsidian]].

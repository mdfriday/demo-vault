# Move from the Friday plugin

## Goal

Keep writing in Obsidian with the two plugins that replaced Friday. You choose the one you need. If you already paid for Friday, you can apply for one free year of both.

The original Friday plugin stops receiving updates after **January 20, 2027**. It is not removed from your vault on that date. After that date it just stops getting new versions.

## What you get

Friday is now two plugins:

- [MDFriday Publish](https://obsidian.md/plugins?search=mdfriday-publish) turns a note or a folder into a website.
- [MDFriday Sync](https://obsidian.md/plugins?search=mdfriday-sync) syncs your vault across devices.

Install one or both. You do not have to take the one you will not use.

**If you already paid for Friday, you can apply for one free year of the new service** (MDFriday Sync and MDFriday Publish). It is not applied automatically. Ask in the [Discord community](https://discord.gg/t7FHJ6qNzT) (`#help`), or email [support@mdfriday.com](mailto:support@mdfriday.com).

## Prerequisites

- Obsidian desktop for Publish. Publish does not run on phone or iPad
- The original Friday plugin can stay enabled until the new one works for you

## Steps

1. Install **MDFriday Publish**, **MDFriday Sync**, or both from Community Plugins. Search `mdfriday-publish` or `mdfriday-sync`
2. There is no import of the old plugin’s settings. Publish starts from a right-click on a note or folder. Sync is set up inside the Sync plugin, not from Friday’s old publish form
3. Publish once, or complete a first sync, and confirm the result is the one you wanted. A new Publish site gets a new share link. The new plugin does not move an old Netlify, FTP, or self-hosted site onto that link
4. When the new plugin does the job you used Friday for, disable the original Friday plugin in Community Plugins. Leave it installed until you are sure

## Confirm success

- The new plugin is enabled and you have published or synced once
- You know the old plugin will not get updates after January 20, 2027
- If you paid for Friday, you have sent the application. The free year starts when that application is accepted, not when you install

## Common failures

| Symptom | What to do |
| --- | --- |
| The free year is not on the account yet | It is an application, not an automatic credit. Write in Discord `#help` or email support@mdfriday.com |
| The old public URL does not open the new site | Publish creates a new share link. Old hosts are not redirected |
| Not sure which plugin to install | Publish is the website. Sync is the vault copy across devices. Install only what you used Friday for |

# Themes in MDFriday

Applies to plugin **v26.10.2**.

← [[index|MDFriday Publish Help]]

You do not write CSS. The panel lists only the themes that fit what you selected. Other families on the website (books, slides, landing pages) are not in this picker.

| You are publishing | What to select | What you get |
| --- | --- | --- |
| One note that should look like Obsidian | **Faithful** | The reading view at the moment you publish, including community-plugin output that can be frozen as HTML. Clicks, filters, and other interaction are gone |
| One note that should look like its own web page | **Single-page theme** | One of six Notes looks. No graph and no site search |
| A folder of linked notes | **Wiki** | Quartz, Creator, Flint, or Jasper. A folder cannot use Faithful |

The first time you pick a theme, the plugin downloads a pack and caches it. Later switches are local.

> [!info] Locks
> A theme can require a plan or a purchase. If it is locked, the panel shows why. Pick another theme, or upgrade. The website catalog is <https://mdfriday.com/themes/>.

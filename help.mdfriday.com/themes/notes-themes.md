# Notes themes in MDFriday

Applies to plugin **v26.10.2**.

Use these only for **one note**, with the mode set to **Single-page theme**. A folder never shows this list. The default is **Paper**.

If the page should match the vault's reading view, use [[../publish/modes|Faithful]] instead.

| Theme | Use it when |
| --- | --- |
| **Paper** | You want a warm reading page. This is the default |
| **News** | The note is an article and should feel like a publication |
| **Card** | You want a plain, technical page |
| **Magazine** | The note has a cover and should feel louder |
| **Minimal** | You want a dark, quiet page. This is a dark look, not a light/dark switch |
| **Business** | The note is a report |

All six render Mermaid and math (KaTeX). None of them include a graph or site search. They do not include a dark-mode toggle. **Minimal** is dark by design.

Every theme, including Faithful, adds a **Built with MDFriday** footer. You cannot turn that footer off, and you cannot replace it with an ICP filing line.

Switching theme does not change which notes are public. Preview after you switch so you see the new CSS. See [[choose-theme|How to choose a theme]].

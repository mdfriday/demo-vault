# Guest / Free / Personal

## 对照表（插件 UI + 设计规范 + 官网定价交叉核对）

| 能力 | Guest | Free | Personal |
| --- | --- | --- | --- |
| 定位 | 第一次试试 | 持续免费发布 | 自己的域名与长期站点 |
| 价格 | 免费 · 无需账号 | 免费 · 注册 | 官网：**$5/月**（年付 $60）或月付 **$6/月**（以结账页为准） |
| 站点数量（插件文案） | **1** | **最多 3** | **不限** |
| 存储 | **5 MB** | **50 MB** | **1 GB** |
| 保留 | 下一个 **UTC 00:00** 清空 | **每月 1 日**清空 | **永久保留** |
| 首次 Turnstile | 需要 | 跳过 | 跳过 |
| 原样 / 单页 / Wiki | ✓ | ✓ | ✓ |
| CDN / 分享链接 | ✓ | ✓ | ✓ |
| 认领 Guest 同 URL | — | ✓ | ✓ |
| 访问密码 | ✓ | ✓ | ✓ |
| 自定义域名 + HTTPS | ✗ | ✗ | ✓（最多 3 个） |
| 发布历史 + 回滚 | ✗ | ✗ | ✓ |

> [!tip] 超配额时
> 存储或站点超限会**阻止新的发布**；已上线站点通常仍可访问（官网定价 FAQ 同旨）。可删除/撤销不用的站，或升级。

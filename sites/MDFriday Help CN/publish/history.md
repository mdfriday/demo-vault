# 发布历史与回滚

## 目标

查看某项目历次**发布**版本，必要时回滚到旧版本（站点仍保持公开）。

## 前置条件

- **Personal** 计划才提供可操作历史
- Guest / Free：历史 Tab 为锁定空态（🔒）+ 升级引导
- 只有 **Publish** 写入历史；**预览永不进入历史**

## 步骤（Personal）

1. 右侧面板打开 **历史** Tab
2. 浏览版本条目（时间、模式、主题、URL、是否 Live）
3. **查看**：打开该版本页面
4. **回滚**：确认后用该历史版本覆盖当前已发布内容（站点仍公开）
5. 对当前 Live 条目还可 **撤销发布**（见 [[unpublish|撤销发布]]）

## 结果确认

- 回滚后公开 URL 内容变为旧版本
- 项目状态仍为 **已发布**（与「撤销发布」不同）

## 常见失败

| 现象 | 处理 |
| --- | --- |
| 历史是空的锁 | 升级 Personal，或确认是否只做过预览没发布 |
| 回滚失败 | 网络 / 配额；查看 Notice；Discord 反馈 |

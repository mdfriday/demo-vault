# 本地预览

## 目标

在**不上线**的情况下，于本机浏览器查看构建结果。

## 前置条件

- 桌面端；已在右侧面板选好发布对象与模式 / 主题

## 步骤

1. 打开右侧 **发布** Tab
2. 点底部次要按钮 **「预览」**
3. 等待「正在构建… / 本地预览 · 启动本地服务」
4. 成功后打开本机 URL（形如 `http://127.0.0.1:端口/`）
5. 看完后可 **停止预览**

## 结果确认

- Badge 为 **本地预览**（不是「已发布」）
- Helper：**预览仅在本机有效，不会写入发布历史**
- **不需要** Guest Turnstile；Guest 也可预览

## 常见失败

| 现象 | 处理 |
| --- | --- |
| 预览空白 | 看构建是否报错；原样模式依赖库外观/插件，可换主题模式对比 |
| 端口打不开 | 本机防火墙 / 杀软；停止预览后重试 |
| 误以为已上线 | 看 URL 是否为 localhost；公开分享请走「发布」 |

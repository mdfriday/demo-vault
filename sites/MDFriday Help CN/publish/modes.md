# 发布模式

## 目标

搞清楚面板里的 **原样发布 / 单页主题 / Wiki 发布** 分别什么时候出现、默认是什么。

## 规则（与源码一致）

| 选择 | 可选模式 | 默认（右键直接发布） |
| --- | --- | --- |
| **笔记（note）** | `faithful` 原样 · `themed` 单页主题 | **原样**，无主题、无密码 |
| **文件夹（folder）** | 仅 `themed`（UI 称 Wiki 发布） | **Wiki**，默认主题 slug **`quartz`**，无密码 |

> [!info] 文案对照（zh-CN）
> - 原样发布：保留本地预览感（主题、社区插件渲染、CSS snippets）
> - 单页主题：精选单页主题，可带 Live demo
> - Wiki：Quartz / Obsidian Publish 风格数字花园 · 图谱 · 多页
> - 文件夹无法原样：多页结构需要 Wiki 引擎解析双向链接与图谱

## 怎么选（实用）

| 场景 | 建议 |
| --- | --- |
| 给同学/同事看「和库里长得一样」 | 单篇 → **原样** |
| 要更像独立网页 / 品牌感 | 单篇 → **单页主题** |
| 一堆互相链接的笔记 | **文件夹 → Wiki** |

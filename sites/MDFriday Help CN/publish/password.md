# 访问密码

## 目标

让访客打开链接前必须输入密码；适合简报、对内材料等「有链接但仍需门槛」的场景。

## 前置条件

- 任意计划（Guest / Free / Personal）均可使用访问密码（以面板高级选项为准）
- 密码在**发布时提交**；插件本地只记「是否启用」类标记，**不把明文密码长期写进 pathConfigs**

## 步骤

1. 打开右侧面板 → **高级选项**
2. 打开 **访问密码**，填写密码（占位提示：**留空则公开访问**）
3. [[local-preview|预览]]（若启用加密门，预览也可能走门控页）后 **发布**
4. 把链接与密码分通道发给对方

## 结果确认

- 无痕 / 未登录访客打开公开 URL 时先看到密码门
- 取消密码：清空后再次发布

## 相关链接

- [[unpublish|撤销发布]]（比改密码更彻底的下线）
- <https://mdfriday.com/solutions/share-a-note/>

## 常见失败

| 现象 | 处理 |
| --- | --- |
| 设了密码但仍公开 | 确认已成功「再次发布」；勿只改面板未发布 |
| 自己也进不去 | 核对密码空格/全角；用撤销后重新发布 |

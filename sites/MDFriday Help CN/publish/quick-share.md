# 快速分享

## 目标

用命令面板最快打开当前笔记的发布流程，并生成本地预览，便于确认后一键发布。

## 前置条件

- **仅桌面端**（移动端会提示「快速分享仅在桌面版本可用」）
- 当前视图是 Markdown 笔记

## 步骤

1. 打开要分享的笔记
2. 命令面板运行 **「快速分享」**（`quick-share`）
3. 等待提示「正在准备快速分享…」→「准备就绪！点击「发布」即可分享您的笔记」
4. 在右侧面板确认效果后点 **发布**

> [!tip] 和「发布到 MDFriday」命令的区别
> - **快速分享**：侧重打开面板并走预览准备
> - **发布到 MDFriday**（`quick-publish`）：对当前文件执行发布向流程  
> 两者都要求桌面端 + 已打开 Markdown。

## 结果确认

- 右侧面板出现当前笔记；通常已有预览结果可打开
- 真正对外分享仍以「发布成功」后的公开 URL 为准

## 常见失败

| 现象 | 处理 |
| --- | --- |
| 「请先打开一个 Markdown 文件」 | 先聚焦 md 标签页 |
| 快速分享失败 | 看 Notice 错误原文；再试「在 MDFriday 中打开」手工预览 |

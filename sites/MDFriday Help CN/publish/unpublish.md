# 撤销发布

## 目标

让公开链接失效（访客看到 404），直到你再次发布。

## 前置条件

- 项目当前为已发布（Live）
- 各计划均可撤销（以面板为准）；与「回滚」不同

## 撤销 vs 回滚

| | 撤销发布 | 回滚 |
| --- | --- | --- |
| 结果 | 站点**下线** | 仍公开，内容换历史版 |
| 状态 | 已撤销 · 未公开 | 仍为已发布 |
| 设置记忆 | **保留**，方便再发 | 随版本展示可能变化 |
| 计划 | 各计划（Success / 历史 Live） | **Personal** 历史 |

## 步骤

1. 发布成功结果页，或历史 Tab 的 Live 条目
2. 点 **撤销发布** / **撤销分享**
3. 确认提示：「撤销发布？访客将看到 404，直到你再次发布。」

## 结果确认

- 状态变为 **已撤销 · 未公开**
- 公开 URL 很快不可访问
- 配置仍被记住，可 **再次发布** 恢复

# 设置

当前 **MDFriday Publish** 设置页非常精简（相对旧版 Friday 的 License / 服务器长列表）。

| 页面 | 内容 |
| --- | --- |
| [[credentials\|Credential（mdf key）]] | 唯一主要设置项 |

Cloudflare API / Share 等环境在**编译期**锁定（生产 → `mdfriday.com`；开发构建可能指向 staging `fsky.top`），**普通用户设置里不再切换**。

计划对比文案也会提示：完整订阅管理在 **设置 → MDFriday** / 账号站，而不是堆在侧栏。

# Credential（mdf key）

## 目标

了解自动签发的发布凭证，并在需要时复制到账号站或其他设备。

## 在哪里

**设置 → MDFriday Publish**（或设置里的 MDFriday 项）→ **Credentials**

## 字段说明

| 项 | 说明 |
| --- | --- |
| Credential (mdf key) | 统一 Key；种类为 guest 或 user（产品内不把种类编码进字符串展示） |
| 尚未创建 | 文案：*Not created yet — issued automatically on first publish.* |
| 已创建 | 显示截断预览；可点复制（*Mdf key copied*） |

> [!warning] 保管
> mdf key 等同于你的发布身份。不要发到公开仓库或截图给陌生人。遗失/泄漏时，应在账号侧按官方流程轮换（以账号站实际能力为准）。

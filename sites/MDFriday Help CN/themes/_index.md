# 主题

MDFriday Publish 的主题来自**在线目录**（首次选用会下载并缓存 pack）。插件按选择类型过滤：

| 选择 | 目录过滤 | 默认 slug |
| --- | --- | --- |
| 单篇 + 单页主题 | `family === 'notes'` | `paper` |
| 文件夹 Wiki | Quartz 族（`family/slug` 含 quartz） | `quartz` |

| 页面 | 内容 |
| --- | --- |
| [[choose-theme\|如何选用主题]] | 面板操作与 Live demo |
| [[notes-themes\|Notes（单页）主题]] | 分享单篇时的外观 |
| [[wiki-quartz\|Wiki / Quartz]] | 文件夹数字花园 |

> [!info] 权益与锁定
> 目录项可有 `free` / `plan` / `purchase` 等访问级别。未授权时 UI 可能锁定（需计划或购买）。以面板实际列表与官网主题页为准：<https://mdfriday.com/themes/>

> [!warning] 不要沿用旧 Friday「500+ Hugo 主题一键导出」叙述
> 当前 Publish 插件侧重点是 **Notes + Wiki（Quartz）** 两套发布行为；具体可选项以你账号 entitlement + 目录 API 返回为准。

# Guest / Free / Personal

## Comparison (plugin UI + design spec + website pricing cross-check)

| Capability | Guest | Free | Personal |
| --- | --- | --- | --- |
| Positioning | First try | Ongoing free publish | Your domain and long-lived sites |
| Price | Free · no account | Free · sign up | Website: **$5/mo** (annual $60) or monthly **$6/mo** (checkout page wins) |
| Sites (plugin copy) | **1** | **Up to 3** | **Unlimited** |
| Storage | **5 MB** | **50 MB** | **1 GB** |
| Retention | Cleared at next **UTC 00:00** | Cleared on the **1st of each month** | **Permanent** |
| First Turnstile | Required | Skipped | Skipped |
| Faithful / single-page / Wiki | ✓ | ✓ | ✓ |
| CDN / share link | ✓ | ✓ | ✓ |
| Claim Guest same URL | — | ✓ | ✓ |
| Access password | ✓ | ✓ | ✓ |
| Custom domain + HTTPS | ✗ | ✗ | ✓ (up to 3) |
| Publish history + rollback | ✗ | ✗ | ✓ |

> [!tip] Over quota
> Storage or site overage **blocks new publishes**; already-live sites usually stay reachable (same idea as the website pricing FAQ). Delete/unpublish unused sites, or upgrade.

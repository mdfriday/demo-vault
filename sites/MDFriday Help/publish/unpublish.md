# Unpublish

## Goal

Make the public link stop working (visitors see 404) until you publish again.

## Prerequisites

- Project is currently published (Live)
- All plans can unpublish (per panel); this is not the same as rollback

## Unpublish vs rollback

| | Unpublish | Rollback |
| --- | --- | --- |
| Result | Site goes **offline** | Stays public; content swaps to a historical version |
| Status | Unpublished · not public | Still published |
| Remembered settings | **Kept** for easy republish | May change with the version shown |
| Plan | All plans (Success / History Live) | **Personal** history |

## Steps

1. Publish-success result page, or the Live entry on the History tab
2. Click **Unpublish** / **Unshare**
3. Confirm: “Unpublish? Visitors will see 404 until you publish again.”

## Confirm success

- Status becomes **Unpublished · not public**
- Public URL stops working soon
- Config is still remembered so **Publish again** can restore it

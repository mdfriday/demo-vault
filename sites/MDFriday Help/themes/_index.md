# Themes

MDFriday Publish themes come from an **online catalog** (the first use downloads and caches a pack). The plugin filters by selection type:

| Selection | Catalog filter | Default slug |
| --- | --- | --- |
| Note + single-page theme | `family === 'notes'` | `paper` |
| Folder Wiki | Quartz family (`family/slug` contains quartz) | `quartz` |

| Page | Content |
| --- | --- |
| [[choose-theme\|How to choose a theme]] | Panel actions and Live demo |
| [[notes-themes\|Notes (single-page) themes]] | Look for sharing one note |
| [[wiki-quartz\|Wiki / Quartz]] | Folder digital garden |

> [!info] Entitlements and locks
> Catalog items may have access levels like `free` / `plan` / `purchase`. Unauthorized items can lock in the UI (need a plan or purchase). Trust the panel list and the website themes page: <https://mdfriday.com/themes/>

> [!warning] Do not reuse old Friday “500+ Hugo themes one-click export” copy
> The current Publish plugin centers on **Notes + Wiki (Quartz)** as two publish behaviors; available options follow your account entitlement + what the catalog API returns.

# Notes (single-page) themes

Used for **single notes** in `themed` mode. Catalog filter is the Notes family; the default slug in code is **`paper`**.

Best for: sharing a long single page, a report, or an external reading page — more like a standalone web page than **faithful publish**.

If matching the Obsidian reading view matters more, prefer [[../publish/modes|faithful publish]] instead of forcing a theme.

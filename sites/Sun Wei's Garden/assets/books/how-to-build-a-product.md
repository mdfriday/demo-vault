# How to Build a Product

## Framework

1. Name the job-to-be-done in one sentence.
2. Cut scope until a stranger can feel value quickly.
3. Separate cockpit (UX) from engine (core).
4. Dogfood weekly.
5. Let objections reshape the next slice — not the entire identity every time.

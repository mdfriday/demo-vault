# 12. 关键词研究策略

## KNOW（知道）

### 什么是关键词研究？

关键词研究是**找出人们在搜索什么，然后为这些搜索创建内容**的过程。

### 为什么重要？

**没有关键词研究，你是在猜测。**

你可能会花数小时写一篇文章，却发现：
- 没人在搜索它
- 竞争太激烈
- 搜索意图不对

有了正确的关键词研究，你会：
- 知道人们在搜索什么
- 找到易于排名的关键词
- 创建有真实需求的内容

### 核心概念

**三类关键词：**

| 类型 | 搜索量 | 竞争 | 难度 | 例子 |
|------|--------|------|------|------|
| 头部 | 高 | 高 | 难 | "营销" |
| 中段 | 中等 | 中等 | 中等 | "邮件营销" |
| 长尾 | 低 | 低 | 容易 | "如何创建邮件营销活动初学者指南" |

**最好的起点：长尾关键词** - 竞争少，转化好。

## UNDERSTAND（理解）

### 关键词难度vs搜索量

**搜索量：** 每月有多少人搜索

**难度：** 排名有多困难（由现有的竞争内容决定）

```
理想的关键词:
- 高搜索量
- 低难度

现实中很少见。通常你要权衡：
- 新网站应该针对低难度（长尾）关键词
- 随着权威增长，你可以针对更难的关键词
```

### 搜索意图

并非所有搜索的意图都相同。

**4种搜索意图：**

1. **信息性** - 找信息
   - "如何做..."
   - "什么是..."
   - "为什么..."

2. **导航性** - 找到一个特定的网站
   - "[公司名称]"

3. **商业性** - 研究购买
   - "最好的[产品]"
   - "[产品]对比"

4. **交易性** - 准备购买
   - "买[产品]"
   - "[产品]价格"

**重要：** 你的内容意图应该匹配搜索意图。
- 信息搜索不会购买
- 交易搜索意味着他们准备好了

## MASTER（掌握）

### 关键词研究的逐步流程

#### **步骤1：头脑风暴主题**

列出与你的业务相关的所有主题。

例如，如果你提供邮件营销服务：
```
- 邮件营销
- 邮件活动
- 邮件列表
- 自动化邮件
- 邮件设计
- 邮件转化率
- 邮件分析
- ��件最佳实践
```

#### **步骤2：生成关键词变体**

对于每个主题，创建多个关键词变体。

例如，"邮件营销"：
```
- 邮件营销初学者
- 如何做邮件营销
- 邮件营销技巧
- 邮件营销工具
- 邮件营销最佳实践
- 邮件营销策略
- 邮件营销平台
- 邮件营销例子
```

#### **步骤3：研究搜索量和难度**

使用关键词工具检查：
- 每月有多少人搜索
- 排名有多困难

**免费工具：**
- Google Keyword Planner（最准确）
- Ubersuggest（易于使用）
- AnswerThePublic（查看相关问题）
- Keywords Everywhere（浏览器扩展）

**简单流程：**
1. 进入Google Keyword Planner
2. 输入你的关键词
3. 查看搜索量和"竞争水平"
4. 记录结果

#### **步骤4：评估搜索意图**

对于每个关键词，问自己：
- 搜索该关键词的人在寻找什么？
- 这与我的业务相关吗？
- 我能创建最好的答案吗？

例如：
```
关键词："如何做邮件营销"
搜索意图：信息性（他们想学习）
我能排名吗？是，这个主题我很擅长
应该优先处理吗？是，与我的服务相关
```

#### **步骤5：创建目标关键词列表**

为你的网站创建一个目标关键词的电子表格：

```
关键词 | 搜索量 | 难度 | 搜索意图 | 优先级 | 内容想法
-------|--------|------|--------|--------|----------
邮件营销 | 5000 | 高 | 信息 | 低 | 指南
如何创建邮件活动 | 200 | 低 | 信息 | 高 | 教程
邮件营销工具 | 300 | 中 | 商业 | 中 | 对比
...
```

### 关键词竞争分析

#### **步骤1：搜索关键词**

在Google上输入关键词。看看谁排名前10。

#### **步骤2：评估竞争**

```
问题：
- 这些是大公司（大品牌）吗？
- 他们的内容有多好？
- 他们有很多反向链接吗？
- 他们用什么关键词优化的？

如果：
- 全部是大品牌 = 难排名
- 混合大小网站 = 中等机会
- 大多是小网站 = 绝好机会
```

#### **步骤3：找到"排名缝隙"**

```
排名缝隙 = 许多搜索量但竞争少

例如：
"邮件营销初学者"有300个搜索/月
但没有优化很好的内容
这是一个排名缝隙

你应该为其创建内容
```

### 如何使用Google找到关键词

Google实际上是最好的关键词研究工具。

#### **方法1：搜索建议**

```
在Google中输入你的关键词
下拉菜单显示相关搜索
这些是其他人实际搜索的
```

#### **方法2：相关搜索**

```
搜索一个关键词
向下滚动到底部
"相关搜索"部分显示其他相关查询
```

#### **方法3：Search Console**

```
登录Google Search Console
查看"查询"部分
看到你的网站已经排名的所有关键词
```

### 关键词分组

一旦你有了一个关键词列表，按主题分组：

```
主题1：邮件营销基础
- 什么是邮件营销
- 邮件营销初学者
- 邮件营销为什么重要

主题2：创建活动
- 如何创建邮件活动
- 邮件活动模板
- 邮件活动最佳实践

主题3：优化和测试
- 邮件A/B测试
- 邮件主题行优化
- 邮件打开率优化

等等...
```

对于每个主题，创建一篇深入的"支柱"文章，然后链接到相关的子文章。

### 关键词研究常见错误

**错误1：针对头部关键词**
```
不好：针对"营销"
好：针对"如何开始一个邮件营销业务"
```

**错误2：忽视搜索意图**
```
错误：针对购买关键词而创建信息内容
```

**错误3：没有验证搜索量**
```
错误：假设有人搜索，而不检查
使用工具验证
```

**错误4：忽视竞争**
```
错误：无视排名第一的是NASA
在你有权威之前，针对较容易的关键词
```

## 关键要点

1. **长尾关键词是你的朋友** - 搜索量低但竞争也低
2. **搜索意图很重要** - 确保你的内容匹配人们在寻找的
3. **Google是最好的工具** - 建议��相关搜索通常比付费工具更好
4. **竞争分析很关键** - 在你没有权威的地方避免排名不了
5. **关键词分组效率** - 围绕主题创建相关内容集群

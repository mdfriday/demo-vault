### onCreated

Once Deps has been created, we can apply it.
In the flow that creates HugoSites, applying Deps happens in onCreated.

### See it clearly — the onCreate sequence

![HugoSites Main Flow](images/9.0-hugo-sites-main.svg)

From the lower left, onCreate has three parts:

* NewDestinationPublisher: create a publisher for the site
* initializeSiteInfo: initialize site info, and gather the information the site depends on
* newPageCollection: create the page collection. Rendering is done per page, so HugoSites gives each site a collector

#### NewDestinationPublisher

```go
pub, err := publisher.NewDestinationPublisher(
				d.ResourceSpec,
				s.outputFormatsConfig,
				s.mediaTypesConfig,
			)
			...
			s.publisher = pub
```

ResourceSpec comes from Deps. It holds PathSpec, which has the full filesystem information, plus outputFormats and mediaTypesConfig. In our example these are all defaults.
The publisher does not own the current site's config — outputFormatsConfig and mediaTypesConfig.
Holding both the defaults and the customized info lets us customize for the current site.

#### initializeSiteInfo

```go
func (s *Site) initializeSiteInfo() error {
	// Assemble dependencies to be used in hugo.Deps.
	s.Info = &SiteInfo{
		title:        "title",
		relativeURLs: s.Cfg.GetBool("relativeURLs"),
		owner:        s.h,
		s:            s,
	}
	return nil
}
```

In our example the basic info is simplified. You can see that the basic information the site needs, such as the title, is gathered here.

#### newPageCollection

```go
...
pm := &pageMap{
    contentMap: newContentMap(),
    s:          s,
}
s.PageCollections = newPageCollections(pm)
...
```

PageCollections is the set of pages. It can provide services such as looking up a page.

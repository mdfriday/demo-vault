# Facebook Ads

## Overview

Facebook Ads is a **paid advertising platform** where you pay per click/impression to reach Facebook's 3 billion users with laser-targeted ads.

> [!IMPORTANT]
> **Facebook Ads ≠ Facebook Marketing**
>
> - Facebook Marketing: Organic posts, community building (free)
> - Facebook Ads: Paid advertising campaigns (you pay)

## When to Use Facebook Ads

### Best Use Cases

1. **Email List Building** (Best ROI)
   - Lead magnet offers
   - Cost per signup: $0.50-$3
   - Builds owned audience

2. **Product Sales** (E-commerce)
   - Retargeting website visitors
   - Dynamic product ads
   - Best for repeat customers

3. **Brand Awareness**
   - Video views
   - Reach new audiences
   - Lower conversion expectations

4. **Event Promotion**
   - Webinars, conferences
   - Specific audience targeting
   - Drive registrations

### Not Ideal For

❌ B2B services (LinkedIn Ads better)
❌ High-ticket professional services
❌ Very specific technical audiences
❌ Extremely niche products (small audience)

## Module 1: Campaign Setup

### Ad Account Structure

```
Ads Manager (top level)
    ├── Campaign 1 (Goal: Email list building)
    │   ├── Ad Set 1 (Audience A, Budget $10/day)
    │   │   ├── Ad 1 (Image version)
    │   │   ├── Ad 2 (Video version)
    │   │   └── Ad 3 (Carousel version)
    │   └── Ad Set 2 (Audience B, Budget $10/day)
    └── Campaign 2 (Goal: Product sales)
```

### Campaign Objectives

| Objective | Best For | Billing | Results |
|-----------|----------|---------|---------|
| **Traffic** | Website visits | CPM/CPC | Clicks to site |
| **Conversions** | Sales, signups | CPC/CPA | Tracked actions |
| **Lead Generation** | Email signups | CPL | Leads captured |
| **Video Views** | Brand awareness | CPV | Video completions |
| **Reach** | Maximize exposure | CPM | Impressions |
| **Engagement** | Likes, comments | CPE | Engagement actions |

**Recommendation for Beginners**: "Conversions" objective (automatic optimization)

## Module 2: Audience Targeting

### Targeting Layers

#### 1. Demographic Targeting
- Age range
- Gender
- Location (country, state, city, radius)
- Language
- Education level
- Income level

#### 2. Interest Targeting
- Interests (hobbies, behaviors)
- Facebook Page likes
- Categories (entertainment, sports, etc.)

#### 3. Behavior Targeting
- Purchase history
- Device usage
- Connection type (WiFi, mobile)
- Recent purchases
- Digital activities

#### 4. Custom Audience
- Upload your email list (retarget existing customers)
- Website visitors (retarget with different offer)
- Customer list (look-alike audience)

#### 5. Lookalike Audience
- Create audience similar to your best customers
- Facebook matches them based on patterns
- Often outperforms interest targeting

**Power Strategy**: Start with lookalike audience (70% of your best customers)

### Audience Size

**Ideal Audience Size**:
- Too small: High CPC (expensive)
- Too large: Unfocused, low relevance
- Sweet spot: 500K - 5M people (depending on niche)

**Red Flags**:
- Audience < 100K: Too narrow
- Audience > 20M: Too broad
- Audience 0: Targeting doesn't match any users

## Module 3: Ad Creative Strategy

### Ad Formats

#### Image Ads
- Single static image
- Headline + Description + CTA button
- Best for: Awareness, straightforward message

#### Video Ads
- 6 second to 2+ minute videos
- Can be skippable or non-skippable
- Best for: Engagement, storytelling

#### Carousel Ads
- Multiple images/videos user swipes through
- Different image per product option
- Best for: E-commerce, multiple products

#### Collection Ads
- Shoppable catalog
- Users browse without leaving Facebook
- Best for: Product discovery

#### Lead Ads
- Sign-up form inside Facebook
- Easier than click-away to website
- Best for: Quick email capture

### Creative Best Practices

**Video Ads**:
- First 3 seconds: Hook viewers
- Use captions (sound off default)
- Keep under 15 seconds
- Include CTA in video

**Image Ads**:
- High-quality, eye-catching image
- Clear focal point
- Avoid too much text
- Consistency with brand

**Copy (Headline + Description)**:
- Benefit-driven headline
- Address pain point or desire
- Clear call-to-action
- Short, scannable text

**CTA Button**:
- "Learn More" - General
- "Sign Up" - Lead generation
- "Shop Now" - E-commerce
- "Download" - PDF/resource

## Module 4: Budgeting & Bidding

### Budget Setup

**Daily Budget**:
- Facebook minimum: $5/day per ad set
- Recommended: Start with $10-20/day
- Total: $50-100/day to start

**Example Budget**:
- Campaign: Email list building
  - Ad Set 1 (Audience A): $10/day
  - Ad Set 2 (Audience B): $10/day
  - Total daily: $20
  - Total monthly: ~$600

### Bidding Strategies

#### Automatic Bidding (Recommended)
- Facebook optimizes automatically
- Good for learning
- Lower barrier to entry

#### Manual Bidding
- You set maximum bid
- More control
- Requires experience

#### Bid Strategies by Objective
- **Conversions**: Bid for conversions (oCPM)
- **Traffic**: Bid for clicks (CPC) or impressions (CPM)
- **Lead Generation**: Bid for leads (Cost per Lead)

### Cost Expectations

| Objective | Typical CPC | Typical CPL |
|-----------|-----------|-----------|
| **Traffic** | $0.50-$2 | N/A |
| **Lead Gen** | $0.50-$3 | $1-$5 |
| **Conversions** | $1-$5 | N/A |
| **Video Views** | $0.01-$0.05 | N/A |

**ROI Formula**:
$$\text{Profitable if: } (CPL \times Conversion Rate) < Customer Value$$

## Module 5: Launch & Optimization

### Pre-Launch Checklist

- [ ] Clear ad copy without typos
- [ ] High-quality images/video
- [ ] Landing page or lead form created
- [ ] Pixel installed and tracking
- [ ] Budget set appropriately
- [ ] Audience targeting confirmed
- [ ] Ad schedule set (all hours)
- [ ] Bid strategy chosen

### First 24 Hours

**What to Watch**:
- CPM (cost per impression) - should drop as Facebook learns
- CTR (click-through rate) - should improve first day
- CPC (cost per click) - should decrease
- Conversion rate - too early to judge

**Don't Optimize YET**: Facebook needs 50-100 conversions to learn

### After 1 Week

**Metrics to Review**:
- Cost per click
- Click-through rate
- Cost per lead/conversion
- Quality score (relevance)

**Optimization Decisions**:
- If CTR < 1%: Improve ad creative
- If CPC > $3: Refine audience
- If cost per conversion > budget: Pause and adjust
- If performing well: Increase budget 20%

### Ongoing Optimization

**Week 2-3**:
- Pause underperforming ad sets
- Scale winning ad sets (increase budget 20%)
- Test new audience layers
- A/B test different creatives

**Month 2+**:
- Add new campaigns (different offer/audience)
- Test different landing pages
- Optimize for ROAS (return on ad spend)
- Build lookalike from converters

## Module 6: Advanced Strategies

### Retargeting (Remarketing)

**Strategy**: Show ads only to people who've visited your site

**Process**:
1. Install Facebook Pixel on website
2. Create audience from pixel data (30-day window)
3. Create retargeting campaign
4. Usually cheaper (warmer audience)
5. Higher conversion rates

**Example**:
- User views product page but doesn't buy
- Next day they see ad: "Still interested? Here's 10% off"
- Much higher conversion rate than cold traffic

### Sequential Messaging

Show different ads based on user journey:

```
Ad 1: Problem awareness
     ↓
Ad 2 (if clicked): Solution introduction  
     ↓
Ad 3 (if visited site): Specific offer
     ↓
Ad 4 (if added to cart): "Don't forget, limited stock!"
```

### Value Proposition Testing

Test different offers:
- Free resource
- Discount offer
- Guarantee/risk-reversal
- Urgency (limited time)
- Scarcity (limited quantity)

**Winner**: Scale what works, pause what doesn't

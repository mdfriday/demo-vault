## What is This?

Technical SEO ensures search engines can properly discover, understand, access, and present your website to users.

## KNOW | Foundation

### Key Foundation Points from the Course

- Homepage title and meta description must be editable
- Website must connect to Search Console
- Page speed must meet standards
- Site must pass mobile-friendliness tests
- Search engines must be able to index your pages
- HTTPS must be enabled

### Why Technical Foundation Matters

If your website:
- Loads slowly
- Doesn't work on mobile
- Isn't properly indexed
- Has confusing titles/descriptions

Even great content loses traffic and conversions.

## UNDERSTAND | Deep Dive

### Technical SEO Goal Isn't "Advanced Techniques"—It's "Reduce Losses"

Its value is preventing these problems:
- Users bounce before content loads
- Google can't crawl your pages
- Search results show confusing snippets
- Mobile users have terrible experience

### Speed and Mobile Aren't Just SEO—They're Conversion Issues

The course notes that slow sites lose:
- Page views
- User satisfaction
- Conversion rates

So technical SEO is actually a business problem, not just a search problem.

## MASTER | Execution

### Priority Technical Tasks (In Order)

1. Set homepage title and meta description
2. Connect to Search Console and verify
3. Submit XML sitemap
4. Fix PageSpeed issues (prioritize images)
5. Verify mobile-friendliness
6. Ensure HTTPS works throughout

### Optimization Priority (Easy to Hard)

- Optimize image sizes and formats first
- Then implement caching and compression
- Then minify CSS/JavaScript
- Then continuously monitor performance

### Knowledge Checklist

- [ ] Is homepage title and meta description set?
- [ ] Is Search Console connected and verified?
- [ ] Is sitemap submitted?
- [ ] Does page speed meet basic standards?
- [ ] Does mobile version work smoothly?
- [ ] Can key pages be indexed?

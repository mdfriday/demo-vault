## What is This?

On-page SEO means writing and structuring a page so it's easy for both users AND search engines to understand exactly what the page is about.

## KNOW | Foundation

### Key Elements the Course Emphasizes

- One page focuses on one primary keyword
- Title tag (page title)
- URL structure
- Meta description
- Image filenames and alt text
- Keyword appears early in content
- H2/H3 heading structure
- External and internal links
- Content length and readability
- Social sharing capability

### The Goal

Not "keyword stuffing," but making pages stronger in relevance, readability, AND click-through rates.

## UNDERSTAND | Deep Dive

### What Search Engines Evaluate

While engines consider many signals, for individual pages the strongest signals include:

- Is the title accurate?
- Is the URL clear and readable?
- Does the opening quickly establish the topic?
- Is content structure logical?
- Do images have descriptive filenames and alt text?
- Does it reference authoritative related resources?

### What Users Evaluate

On search results page, users see:
- Title
- Meta description

After clicking, users first notice:
- Does the opening match the promise?
- Are subheadings clear?
- Is content easy to scan?
- Is this worth staying on?

So On-page SEO serves both **Google AND humans**.

## MASTER | Execution

### Page Optimization Sequence

1. Identify primary keyword for the page
2. Write a clear, benefit-focused title using that keyword
3. Create short, readable URL using hyphens between words
4. Write meta description emphasizing user benefit
5. In first 100 words, clearly establish the topic
6. Organize content using H2/H3 headings
7. Insert relevant images with descriptive filenames and alt text
8. Link to related authoritative external sources
9. Link to related internal pages
10. Verify the page is scannable, readable, and shareable

### Title and Description Strategy

- **Title**: Tells search engines "this page is about..."
- **Description**: Tells users "here's why you should click..."

### Knowledge Checklist

- [ ] Does the page focus on one primary keyword?
- [ ] Is the title clear, specific, and clickable?
- [ ] Is the URL short and readable?
- [ ] Does the description highlight benefits?
- [ ] Does the opening quickly state the topic?
- [ ] Have I used subheadings, images, internal/external links effectively?

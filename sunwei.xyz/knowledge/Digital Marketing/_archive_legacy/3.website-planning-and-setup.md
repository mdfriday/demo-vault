# 3. 网站规划与建设

## KNOW（知道）

### 什么是网站？

在数字营销中，你的网站是你的**营销中心**。它是：
- 你拥有和控制的资产
- 所有流量汇聚的地方
- 你展示产品/服务的舞台
- 你收集邮件地址的地方

### 为什么重要？

**你不应该在只属于别人的平台上构建你的业务。**

| 社交媒体平台 | 你的网站 |
|-----------|--------|
| Facebook拥有你的受众 | 你拥有受众的邮箱 |
| 算法可能改变 | 你控制展示规则 |
| 平台可能关闭或禁止你 | 永远在你的控制中 |
| 你的内容可能失去排名 | 你的内容永远存在 |

### 核心概念

一个有效的营销网站需要：
1. **清晰的价值主张** - 访客在3秒内知道你做什么
2. **邮件注册** - 将访客转化为邮件订阅者
3. **内容** - 提供价值，吸引人们回来
4. **转化** - 清晰的行动号召

## UNDERSTAND（理解）

### 网站的三个关键角色

#### **角色1：信息传递**
- 清楚地解释你做什么
- 你解决什么问题
- 为什么是你而不是竞争对手

#### **角色2：邮件列表构建**
- 在网站的每个部分放置邮件注册表单
- 提供有价值的东西来换取邮件地址
- 90%以上的访客永远不会再来，邮件列表是你的备份计划

#### **角色3：内容中心**
- 发布对你的受众有价值的内容
- 帮助他们解决问题
- 建立你的专业知识和信任

### 网站与个人品牌

对于个人品牌或小型企业，网站应该反映：
- 你的个性
- 你的价值观
- 你的专业知识

不应该是：
- 过度专业但没有个性
- 炫耀而没有实质
- 太技术性而不易理解

## MASTER（掌握）

### 建立网站的完整步骤

#### **步骤1：选择平台**

**简单网站/博客：**
- WordPress.com - 简单、便宜（$4-18/月）
- Wix/Weebly - 拖放构建器
- Webflow - 更灵活但需要学习

**复杂的功能（销售、预订等）：**
- Shopify - 电商
- Webflow - 高级设计
- 自建网站 - WordPress.org（需要技术）

**推荐给初学者：**WordPress.com 或 Wix
- 简单设置
- 便宜
- 足够功能强大

#### **步骤2：选择和注册域名**

域名是你网站的地址（例如：yourname.com）

**选择域名时：**
- 尽可能简短
- 易于记住和拼写
- 相关（最好包含你的名字或主题）
- 避免数字和连字符

**注册域名：**
- GoDaddy - 便宜，流量大
- Namecheap - 便宜，客户服务好
- Google Domains - 简单可靠
- 价格通常 $10-15/年

#### **步骤3：设置电子邮件**

使用自己的域名的邮件地址比Gmail更专业：
- yourname@yourdomain.com 比 yourname.123@gmail.com 好

**设置选项：**
- WordPress.com/Wix 通常包含
- Gmail for Business - $6/月/用户
- Zoho Mail - 免费基础计划

#### **步骤4：设计网站结构**

一个有效的营销网站通常包括：

```
首页 (主页)
├─ 清晰的标题说明你做什么
├─ 解决什么问题
├─ 号召行动（邮件注册或购买）
└─ 邮件注册表单

关于页面
├─ 你是谁
├─ 你的背景
├─ 为什么人们应该相信你
└─ 邮件注册表单

博客 / 资源
├─ 发布对你的受众有价值的内容
├─ 针对关键词优化（SEO）
└─ 每篇文章都有邮件注册表单

产品/服务页面
├─ 详细说明你提供什么
├─ 收费结构
├─ 号召行动
└─ 邮件注册表单

联系页面
├─ 邮件或表单
├─ 社交媒体链接
└─ 邮件注册表单
```

#### **步骤5：添加邮件收集功能**

这是关键。大多数访客只会来一次。

**在网站上放置邮件表单的地方：**
1. 首页（顶部和底部）
2. 博客文章（顶部和底部）
3. 每个服务/产品页面
4. 弹出窗口（在退出时，或等待几秒后）
5. 侧边栏或页脚

**提供价值以交换邮件地址：**
- 免费的检查表
- 免费的模板
- 免费的电子书
- 免费的课程
- 早期访问新内容

#### **步骤6：优化以进行转化**

- 快速加载速度（1秒内）
- 移动友好（在手机上看起来很好）
- 清晰的导航
- 高质量的图片
- 清晰的字体
- 清晰的号召行动

#### **步骤7：连接邮件服务**

选择邮件营销平台并将其与网站连接：

**流行的选项：**
- Mailchimp - 免费 (最多500个联系人)
- ConvertKit - 更昂贵但为创作者优化 ($29+/月)
- Brevo (Sendinblue) - 免费计划
- Active Campaign - 功能齐全 ($15+/月)

## 关键要点

1. **拥有你的资产** - 你的网站是你拥有和控制的唯一资产
2. **邮件是优先的** - 网站的首要目标是建立邮件列表
3. **选择适合你的平台** - 不要过度复杂化
4. **速度和设计很重要** - 糟糕的网站赶走访客
5. **持续改进** - 发布后，继续优化和添加内容

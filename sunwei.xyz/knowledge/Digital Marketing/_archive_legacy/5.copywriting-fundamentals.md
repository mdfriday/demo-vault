# 5. 文案写作基础

## KNOW（知道）

### 什么是文案？

文案是**为了销售或采取行动而写的文字**。

简单的定义：文案是销售对话的笔写版本。

### 为什么重要？

**在数字营销中，文案就是你的销售代表。**

相同的产品，有好的文案，可以让 1% 的访客转化；有坏的文案，可能是 0.1%。

转化率差异 = 文案好坏

### 核心真理

**文案最大的秘密：这不是关于你或你的产品。这是关于客户。**

- 坏的文案谈论产品的特性
- 好的文案谈论客户能获得什么

**例子：**
- 坏：这个工具有 50 个自动化功能
- 好：这个工具为你节省 10 小时/周，让你专注于增长

## UNDERSTAND（理解）

### 文案与一般写作

| 一般写作 | 文案 |
|--------|------|
| 目标：通知或娱乐 | 目标：说服或行动 |
| 长篇幅可以 | 简洁是首要 |
| 华丽的语言 | 清晰的语言 |
| 可能没有号召行动 | 总是有一个明确的号召行动 |

### 文案为什么有效

**原因1：触发情感**

人们基于情感做出决定，然后用逻辑来证明。好的文案触发情感：
- 恐惧（失去机会）
- 渴望（获得更好的东西）
- 社会证明（其他人也在做）

**原因2：使用客户的语言**

当你使用客户已经说过的词汇，他们感到被理解。这建立了信任。

**原因3：专注于好处，不是特性**

特性 = 产品的什么
好处 = 客户能做什么

### 常见的文案错误

**错误1：说得太多**
- 访客最多花 10 秒钟阅读
- 用最少的话说最重要的

**错误2：用行业术语**
- 你以为这听起来聪明，但对客户来说这是外国语言

**错误3：专注于特性而不是好处**
- "我们的平台有 API" = 没人关心
- "连接你所有的工具，只需点击几下" = 人们关心

**错误4：没有清晰的号召行动**
- 访客应该知道接下来做什么
- "立即注册"比"了解更多"更好

**错误5：不相信你的听众**
- 不说谎或夸大其词
- 真实的、可验证的好处比虚假的承诺好

## MASTER（掌握）

### 文案的 7 大黄金法则

#### **法则1：从客户的痛点开始**

好的文案开篇会说出客户的痛点，证明你理解他。

**例子：**
```
不好的开始：
"我们是一个营销自动化平台。"

好的开始：
"你每周浪费 10 小时在重复的邮件任务上。
你应该用这些时间来获取新客户。"
```

#### **法则2：展示理想的未来**

描绘使用你的产品后的生活样子。

```
"想象不用手工发送邮件，你的销售自动增长。
想象每周节省 10 小时，用在真正重要的事情上。
这不是幻想。这是现实。"
```

#### **法则3：提供证明**

不要只说，展示。

- 数字和统计数据
- 客户推荐
- 案例研究
- 现场证据

```
"我们的客户平均将其转化率提高了 40%"
"John 在第一个月就赚回了他的投资"
```

#### **法则4：说明反面**

如果他们不采取行动会发生什么？

```
"如果你不自动化你的邮件，你的竞争对手会的。
他们会增长更快，赚更多的钱。"
```

#### **法则5：强调价值，而不是价格**

不要吹嘘你便宜。强调对投资的回报。

```
不好：$99/月
好：$99/月，节省你 10 小时和 $500 工资
```

#### **法则6：创造紧迫感**

给访客一个现在采取行动的理由。

```
"前 100 个注册者获得 50% 折扣。"
"这个报价在周五到期。"
```

#### **法则7：清晰和直接**

不要聪明。不要狡猾。清晰地说。

**这是文案中最重要的规则。**

### ���案结构：改进销售信

一个经过验证的文案结构适用于网页、邮件、广告：

```
1. 标题 (Headline)
   - 抓住注意力
   - 谈论客户的痛点或好处

2. 副标题 (Subheading)
   - 支持标题
   - 澄清或扩展

3. 问题 (Problem)
   - 说出客户的痛点
   - "你在努力...吗？"

4. 坏消息 (Bad News)
   - 阐明这个问题的后果
   - "大多数解决方案都不起作用，因为..."

5. 好消息 (Good News)
   - 介绍你的解决方案
   - "有一个更好的方式..."

6. 社会证明 (Social Proof)
   - 客户推荐
   - 案例研究
   - 数字

7. 好处 (Benefits)
   - 列出主要好处
   - 重点放在结果上

8. 常见问题 (FAQs)
   - 回答他们最后的异议
   - "会很复杂吗？ - 不，需要 5 分钟设置"

9. 号召行动 (Call To Action)
   - 清晰、指挥性的行动
   - "立即开始你的免费试用"

10. P.S.
    - 强化关键好处或创造紧迫感
    - "前 100 个获得 50% 折扣"
```

### 实战文案示例

**例子：营销课程销售页面**

```
标题：
"在 30 天内将你的流量翻倍，甚至不需要花钱在广告上"

副标题：
"一个曾帮助 10,000+ 企业主获得他们第一批客户的逐步系统"

问题：
"你是否在从零开始时感到困惑？
你是否试过所有的渠道，但没有什么有效？
你是否觉得你缺少一些秘密的拼图块？"

坏消息：
"问题不是你。大多数教程都教你太多的战术（特定的平台技巧）
而不是足够的战略（首先了解你的客户）。
结果？你追逐每一个新的闪闪发光的工具，但从未获得结果。"

好消息：
"有一个更好的方式。一个经过时间考验的系统，
从一开始就将你放在正确的轨道上。"

社会证明：
"John 在第一个月赚了他的第一个 $10K
Sarah 在 6 个月内扩展到 6 位数
Mike 为 100+ 个客户设置了这个系统"

号召行动：
"立即获得完整系统 - 限时 50% 折扣"
```

### 文案检查表

在发送任何文案之前：

- [ ] 我在开始时提到了客户的痛点吗？
- [ ] 我使用了我从市场调查中收集的客户的实际语言吗？
- [ ] 我专注于好处而不是特性吗？
- [ ] 我有社会证明吗？
- [ ] 我的号召行动清晰和命令式吗？
- [ ] 一个 10 岁的孩子能理解这个吗？
- [ ] 我是否删除了所有不必要的词汇？
- [ ] 是否有明确的紧迫感或动力立即行动？
- [ ] 我的标题和 P.S. 是最强的部分吗？

---

## 关键要点

1. **文案是销售** - 它的唯一工作是说服或推动行动
2. **从客户开始** - 这不是关于你的，是关于他们的
3. **好处胜过特性** - 告诉他们他们能做什么
4. **清晰胜过聪明** - 一个真诚的信息胜过千个巧妙的短语
5. **使用他们的语言** - 从客户调查中直接引用
6. **证明你的主张** - 数据、推荐、案例研究
7. **总是有号召行动** - 人们应该知道接下来做什么

# 7. 标题写作精通

## KNOW（知道）

### 什么是好的标题？

一个好的标题**在3秒内就能说服某人继续阅读**。

根据调查，8出10个人会阅读标题，但只有2出10个会阅读正文。这意味着标题承担了80%的工作。

### 为什么重要？

- 标题决定了你的邮件是否被打开
- 标题决定了你的广告是否被点击
- 标题决定了你的文章是否被阅读

**一个好的标题可以将转化率增加10倍。**

## UNDERSTAND（理解）

### 标题的三个工作

#### **工作1：获得注意力**
在信息过载的时代，你需要打破人们的自动导航。

#### **工作2：承诺好处**
标题应该承诺读者会从继续阅读中获得什么。

#### **工作3：吸引正确的人**
好的标题吸引你真正想要的客户，排斥其他人。

### 5种能工作的标题模式

#### **模式1：数字标题**
人们喜欢数字。它们很具体。

```
"7个最常见的营销错误（以及如何避免它们）"
"3个步骤在60天内翻倍你的收入"
"10个SEO技巧来主导Google搜索结果"
```

**为什么有效？** 承诺具体的结果和时间框架

#### **模式2：How-To标题**
人们想要实际的帮助。

```
"如何在48小时内获得你第一个1000个邮件订阅者"
"如何写能够转化的标题（完整指南）"
"如何建立一个从零开始的6位数业务"
```

**为什么有效？** 直接、可行、承诺学到新东西

#### **模式3：问题标题**
提出一个他们在思考的问题。

```
"为什么大多数企业无法增长（以及如何避免这个陷阱）"
"你在营销上浪费了多少钱？"
"为什么你的转化率停滞不前"
```

**为什么有效？** 触发认可和好奇心

#### **模式4：好奇心间隙**
提示一些东西但不完全透露。

```
"营销人员不想你知道的一个简单技巧"
"我是如何在一个月内做到什么我花了5年学习的"
"这个古老的技巧每月为我赚$50K"
```

**为什么有效？** 创造悬念，人们想要答案

#### **模式5：承诺标题**
直接说出好处。

```
"增加你的销售额而不增加你的营销预算"
"赚取被动收入在你睡觉时"
"获得高质量的线索，几乎不费力气"
```

**为什么有效？** 清晰、强大、直接

## MASTER（掌握）

### 11条标题写作秘诀

#### **1. 使用数字（特别是奇数）**

```
不好：许多技巧来改进你的网站
好：7个经过验证的方式来增加你的网站流量
```

**为什么？** 3、5、7、9比2、4、6、8更好记。

#### **2. 承诺具体的好处**

```
不好：营销技巧
好：5个营销技巧来增加你的销售额30%
```

#### **3. 使用强大的词汇**

强大的词汇激发情感：
- 秘密、技巧、方法、系统、公式
- 证明、保证、承诺、结果
- 最后、终于、突破、发现

```
不好：关于邮件的信息
好：停止浪费邮件：一个曾帮助1000名创始人的秘密系统
```

#### **4. 提到时间框架**

```
不好：如何赚取更多的钱
好：如何在6个月内将你的收入翻倍
```

**为什么？** 时间框架感觉更可靠和可实现的。

#### **5. 问一个问题**

```
"你知道为什么你的邮件没有被打开吗？"
```

**为什么？** 大脑自动尝试回答问题。

#### **6. 使用括号来承诺额外的好处**

```
"5个销售秘诀（来自100万美元的创始人）"
"增加你的时间（和你的收入）"
```

**为什么？** 括号中的内容增加了可信度。

#### **7. 创造紧迫感**

```
"最后的机会：这周获得50%的折扣"
"发现在其他人之前做什么（竞争对手正在隐藏这个）"
```

#### **8. 说出客户的痛点**

```
"厌倦了浪费时间在无效的营销上？"
"你的电子表格正在杀死你的业务吗？"
```

**为什么？** 当他们在标题中看到他们的问题时，他们停止滚动。

#### **9. 提到一个特定的利基**

```
不好：如何增加你的销售额
好：电商创始人如何在90天内增加销售30%
```

**为什么？** 更具体=更多的点击（来自正确的人）。

#### **10. 添加一个惊人的统计数据**

```
"90%的营销人员犯了这个错误（你也是吗？）"
"我是如何以98%的低成本获得客户的"
```

#### **11. 使用你找到的客户的确切语言**

回到你的市场调查。客户怎么说他们的问题？使用他们的词汇。

```
假设客户说："我总是超卖"
标题：不再超卖：库存管理系统完全改变了我的业务
```

### 标题公式

这里有一些经过验证的公式，你可以直接使用：

**公式1：** [数字] + [描述词] + [名词] + [好处]
```
例子："7个强大的SEO技巧来主导Google搜索"
```

**公式2：** 如何 + [结果] + 而不是 + [反面]
```
例子："如何赚取被动收入而不需要一大笔金钱"
```

**公式3：** [惊人的声明] + （为什么 + [原因]）
```
例子："我在一个月内赚了$100K（而且你也可以）"
```

**公式4：** 发现 + [秘密/方法/系统] + 这 + [有名人/成功的人] + 用来 + [结果]
```
例子："发现多百万富翁用来赚取被动收入的秘密系统"
```

### 测试标题

**在发布任何标题之前：**

- [ ] 当我离开我的句子时，我会再看一眼吗？
- [ ] 我是否在第一句承诺了一个清晰的好处？
- [ ] 我是否使用了强大的词汇？
- [ ] 这是否对我的目标客户有吸引力？
- [ ] 是否有时间框架、数字或紧迫感？
- [ ] 这是否是真的？（不要夸大）

### 数字营销中的标题示例

**邮件主题行：**
- "最后：一个有效的营销系统（不是另一个技巧）"
- "3个客户告诉我这改变了他们的业务"
- "你每周浪费多少？$500? $1000? $5000?"

**社交媒体文章：**
- "这个一个改变我的业务的决定"
- "大多数创始人不知道这个技巧（我在）"
- "如果我早知道这个，我会节省6个月"

**博客文章：**
- "完整指南：如何建立从零到6位数的业务"
- "为什么你的SEO失败（以及如何修复它）"
- "这5个错误正在杀死你的转化率"

---

## 关键要点

1. **标题承担80%的工作** - 大多数人只读标题
2. **使用数字** - 3、5、7更好比形容词
3. **承诺好处，不是特性** - 告诉他们他们会获得什么
4. **时间框架增加可信度** - "在60天内"听起来真实
5. **使用客户的语言** - 从市场调查中的实际措辞
6. **测试和迭代** - 好的标题来自于尝试多个版本

# 4. 受众定位基础

## 这是什么
这篇笔记总结 Facebook 广告里最重要的杠杆之一：定位谁看广告。

## KNOW｜先知道
- Facebook 可按人口属性、位置、兴趣、行为等做定位
- 定位的质量，直接影响点击和转化效率
- 太宽或太窄都可能有问题

## UNDERSTAND｜再理解
- 受众定位不是“越精准越好”，而是“与你的 offer 和数据阶段相匹配”
- 新账户往往需要逐步测试，不应过度自信地一次定死

## MASTER｜最后掌握
- 先从最相关的受众假设开始
- 用 ad set 分拆不同受众做对比
- 结合后续数据不断收紧或扩展

### 检查清单
- [ ] 是否有清晰受众假设
- [ ] 是否分组测试不同定位
- [ ] 是否根据数据而不是主观想象持续调整

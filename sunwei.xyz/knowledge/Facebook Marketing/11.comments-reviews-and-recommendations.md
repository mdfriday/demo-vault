# 11. 评论、评价与 Recommendations 管理

## 这是什么
这篇笔记总结如何管理 Facebook 页面上的评论、评价与 recommendations。它们既是社区秩序问题，也是品牌口碑问题。

## KNOW｜先知道

### 你需要管理的三类反馈
1. **普通评论**：帖子下的互动评论
2. **差评 / 负面反馈**：影响其他用户印象
3. **Recommendations**：用户公开表达是否推荐你的业务

### 课程里的关键动作
- 隐藏、删除、举报垃圾评论
- 必要时封禁明显 spam 用户
- 使用敏感词 / profanity 过滤
- 对负面评价进行主动回应

## UNDERSTAND｜再理解

### 评论区不是“放着不管”的地方
评论区会影响：
- 页面专业度
- 新访客的第一印象
- 互动氛围
- 内容可信度

如果评论区被 spam 占据，或者负面反馈无人回应，页面整体质量会快速下降。

### 处理负面反馈的目标不是“赢辩论”
而是让后来者看到：
- 你有在听
- 你愿意解决问题
- 你是一个认真经营的品牌

所以回应差评时，最有价值的是：
- 承认体验问题
- 表示重视
- 说明改进动作

### Recommendations 比传统星级更偏“公开背书”
课程提到 Facebook 后续把 reviews 更明显地转向 recommendations，本质上是在强化：
- 用户推荐意愿
- 更丰富的标签、文字、照片说明
- 更直接的社会证明

## MASTER｜最后掌握

### 评论管理的执行原则
- 垃圾评论：快速隐藏 / 删除 / 封禁
- 真实问题：公开回应
- 负面评价：优先处理
- 正面反馈：适度感谢和放大

### 一个基本回复框架
1. 感谢反馈
2. 复述问题
3. 表示重视
4. 说明会如何处理或改进
5. 必要时引导私下继续沟通

### 检查清单
- [ ] 页面是否有垃圾评论清理机制
- [ ] 是否开启了必要的 moderation 设置
- [ ] 是否对负面评价及时回应
- [ ] 是否把公开反馈当作品牌信任资产来管理

# 2. Facebook 页面搭建

## 这是什么
这篇笔记总结 Facebook Business Page 的搭建原则：一个页面不只是“存在”，而是要做到可搜索、可理解、可联系、可行动。

## KNOW｜先知道

### 页面创建时最关键的信息
- 页面名称
- 分类
- 页面简介
- 用户名 / vanity URL
- 联系方式
- 网站链接
- 营业时间与地址（如果是本地业务）
- 主 CTA 按钮

### 课程的核心建议
页面名称要尽量接近用户会搜索的名字，而不是内部命名。

## UNDERSTAND｜再理解

### 页面设置的目标不是“填完整”，而是降低理解成本
用户访问页面时通常只会快速扫一眼，所以要让以下问题立即得到答案：
- 这是什么业务？
- 适合谁？
- 我能在这里得到什么？
- 下一步我该点哪里？

### vanity URL 的作用
一个好用户名 / 页面短链接的价值在于：
- 易搜索
- 易分享
- 易记忆
- 易放在邮件签名、名片和其它资料里

### 本地业务比线上业务更依赖资料完整度
如果你有线下门店或服务区域，地址、营业时间、电话会直接影响咨询与到店率。

## MASTER｜最后掌握

### 创建页面的推荐顺序
1. 用品牌名或高可识别名称创建页面
2. 选择最贴合业务的分类
3. 写一句清楚的页面描述
4. 上传头像和封面
5. 设置简洁的页面用户名
6. 补全联系方式、网站、地址、营业时间
7. 设置主 CTA 按钮

### 页面简介怎么写
可用一个简单公式：
**你是谁 + 你帮助谁 + 你提供什么价值**

例如：
- 帮助独立开发者提升产品增长效率
- 提供品牌设计、网站搭建与内容营销服务

### 检查清单
- [ ] 页面名称是否适合用户搜索
- [ ] 页面描述是否清晰说明业务内容
- [ ] vanity URL 是否简洁好记
- [ ] 联系方式和网站是否已补全
- [ ] 主 CTA 是否和业务目标一致

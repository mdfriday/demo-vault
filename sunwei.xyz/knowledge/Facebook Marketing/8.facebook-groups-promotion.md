# 8. Facebook Groups 的帮助型推广

## 这是什么
这篇笔记总结如何在 Facebook 群组里推广业务，但不是硬发广告，而是通过“先帮助、后引导”的方式建立信任。

## KNOW｜先知道

### 课程的核心原则
在 Facebook Groups 里，**不要上来就贴产品链接**。
你要先成为一个有帮助的人，而不是一个急于推销的人。

### 课程里推荐的切入方式
- 先找与你目标用户匹配的群组
- 看成员是否活跃、讨论是否频繁
- 用 `Ask Me Anything` 式帖子切入
- 在回答里自然引导到你的网站或服务

## UNDERSTAND｜再理解

### 为什么群组不适合硬广
因为群组的本质是：
- 讨论
- 互助
- 经验交换
- 社群关系

如果你只丢链接，往往会：
- 很快被忽略
- 被群主删除
- 甚至被封禁

### 真正有效的群组打法
是先通过内容和回答建立：
- 权威感
- 好感
- 被需要感

等别人开始问你问题时，你再引导到：
- 网站文章
- 服务页面
- 产品说明
- 更深一步的咨询方式

## MASTER｜最后掌握

### 群组推广的执行流程
1. 搜索与你业务相关的关键词
2. 选择活跃且目标用户匹配的群组
3. 观察一段时间，理解群规与话题风格
4. 先回答问题、参与讨论
5. 再尝试发一个帮助型主帖，如 AMA / FAQ / 经验分享
6. 在评论里自然地提供更深资源链接

### 判断一个群组是否值得投入
- 成员量够不够
- 活跃度高不高
- 问题是否与你业务相关
- 管理氛围是否允许高质量经验分享

### 检查清单
- [ ] 我是否先筛选了高质量群组
- [ ] 我是否避免了上来就发广告链接
- [ ] 我是否用帮助型内容切入
- [ ] 我是否在互动后再自然引导到站外资源

## What is This?

This note covers the first critical step of Google Analytics: create account, establish property, install tracking code, ensure data flows correctly from the start.

## KNOW | Foundation

### Key Prerequisite Facts

- Correct installation is foundational—everything downstream depends on it
- Installation errors cascade through all future reports
- Initial setup typically involves: account creation → property creation → data streams/tracking code

## UNDERSTAND | Deep Dive

### Why "Correct Installation from Day 1" Matters

Data analysis doesn't start with "viewing reports"—it starts with "is collection working correctly?"

If installation is:
- Missed entirely → no data
- Installed twice → duplicate data
- Installed in wrong location → incomplete data

All conclusions become unreliable.

## MASTER | Execution

### Setup Sequence

1. **Define Site Structure & Tracking Scope**
   - Which properties/pages need tracking?
   - What's the overall site architecture?
   - Multiple domains or subdomains?

2. **Complete Account & Property Configuration**
   - Create Google Analytics account
   - Set up properties for each site/app
   - Configure data streams

3. **Install Tracking Code**
   - Place tracking code in correct location
   - Use tracking code appropriate for platform (Google tag, gtag.js, etc.)
   - Ensure code fires on all pages

4. **Verify Installation with Real-Time Report**
   - Use real-time report to confirm data collection
   - Manually visit site, verify hits appear in real-time
   - Test key conversion paths

### Knowledge Checklist

- [ ] Is tracking code correctly installed?
- [ ] Have I verified installation using real-time reports?
- [ ] Is the scope clear (which properties/pages track)?

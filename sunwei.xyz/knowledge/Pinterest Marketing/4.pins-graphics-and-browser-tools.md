## What is This?

This note summarizes Pinterest's core content unit—pins—and how to design visual content for platform spread while using helper tools to increase publishing efficiency.

## KNOW | Foundation

- Pins are Pinterest's basic distribution unit
- Image design, size, text overlay, and readability all matter
- Browser tools help you save and publish content more efficiently

## UNDERSTAND | Deep Dive

- Pins must not just be beautiful but help users understand "what is this and is it worth clicking?"
- Good Pinterest content typically has strong information visibility and collection value

## MASTER | Execution

- Design clear, vertical, readable image assets
- Keep titles/image text consistent with landing pages
- Use browser tools to simplify save-and-publish workflow

### Knowledge Checklist

- [ ] Are images clear and eye-catching in feeds?
- [ ] Is topic understandable at a glance?
- [ ] Does landing page match pin promise?

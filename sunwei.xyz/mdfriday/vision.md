# MDFriday Vision

## Vision

> Help people turn knowledge into businesses.

## Product positioning

> Build websites that help knowledge creators grow, sell, and serve.

## What MDFriday Publish is

An Obsidian plugin: right-click a note or a folder and publish it as a static website.

- **Local build**: the website is generated on your own computer.
- **Cloudflare CDN**: once published, it's served worldwide through a CDN.
- **No Git, terminal or tokens**: no GitHub repository or deploy setup needed.
- **AS mode**: faithfully reproduces how the note renders in Obsidian.
- **Multiple themes**: the same notes, different looks.
- **Selective publish**: publish only the notes or folders you want to make public.

This website, sunwei.xyz, is published from an Obsidian folder with MDFriday.

## Current stage

MDFriday Publish has just entered the international market. This is not the growth stage, not the scaling stage, and not the revenue-optimization stage.

- Understanding users > number of features
- Number of conversations > amount of traffic
- Product direction > revenue optimization
- Speed of learning > speed of development

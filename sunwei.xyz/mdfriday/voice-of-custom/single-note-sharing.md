# Single-note Sharing

← [[mdfriday/voice-of-custom/index|Voice of the Customer]]

## What users are saying

"I just want to send this one note to someone." A whole Publish site or GitHub is too heavy, while copy-paste breaks the formatting and falls out of sync with the original. Competitors already serve this scenario: Share Note, JotBird, Docferry, Obsius and others. What users care about: theme and content fidelity, optional encryption, **links that don't expire**, and internal links from the original that still work.

> [!info] Signal (approximate)
> ~11 VOC cards · ~9 YouTube comments (mostly recommending Share Note as the better option).
> Ranked **#15**: the smallest conversion entry point, and competitors already hold it.

## Why it hurts

- **Sharing is the most frequent, lightest publishing need.** It's often the first moment a user needs to "turn a note into a web page".
- **Building a site for one note costs too much.**
- **Expiring links break trust.** A link that stops working is embarrassing for both the sender and the recipient.

## How people cope today

- Single-note sharing plugins such as Share Note (full theme + optional encryption), JotBird (no sign-up) and Obsius.
- Exporting a PDF or sending a screenshot.
- Chinese users substitute cloud docs such as Feishu; see [[chinese-community-voices|Chinese Community Voices]].

## MDFriday's response

- **Right-click to publish a single note + AS mode fidelity + switchable themes**: a single note can be published as a website too.
- **Guest needs no sign-up** to publish one note, which fits this scenario best.
- **Watch the conflict**: Guest is cleared at the next UTC midnight and Free on the 1st of each month, which runs straight into the "expiring links, I cannot accept that" complaint. Make it clear that anything that needs to last should use Personal (kept permanently).
- Encrypted sharing, revoke at any time (unconfirmed).

## Open questions

- How many users who publish a single note as a Guest upgrade to Free / Personal? This is the smallest conversion funnel.
- When publishing a single note, how are internal links to other notes handled (unconfirmed)?
- Is the clearing rule prominent enough on the publish-success page?

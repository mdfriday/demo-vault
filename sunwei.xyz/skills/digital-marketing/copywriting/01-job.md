Do this before topic, headline, or body. If you cannot fill the three lines, ask. Do not start the draft.

## 1. One reader

Write one sentence: who they are and what they are trying to do right now.

Use a situation, not a demographic. "A marketer who wants the email opened" is a reader. "Adults 25–40" is not.

If research quotes were provided, borrow their situation from those words. Do not upgrade them into a persona.

## 2. One action

Write the single thing this piece asks them to do. Examples: read the next section, start the free account, reply, buy.

If the request names several actions, pick the one that has to happen first and say you dropped the others. A piece with two primary asks is not done.

## 3. Piece type

Pick one:

| Type | Use when |
| --- | --- |
| Article | The default. Teach or argue, then ask for one action. |
| Email | A subject line has to earn the open. |
| Product description | The page has to explain an offer. |
| Sales page | A long page has to answer objections before the ask. |

## 4. Facts you may use

List only what you were given: what it does, the price, the time it takes, limits, real numbers, real quotes. Empty is allowed. Inventing a row is not.

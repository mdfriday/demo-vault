## Conventions

Every skill uses the same structure, so it's easy for people to read and can be handed straight to an AI agent:

1. **When to use**: when to use it
2. **Goal**: what question it answers
3. **Steps**: the concrete steps
4. **Output**: what it produces
5. **Checklist**: how to tell it was done well

The Digital Marketing Skills use the Agent Skills format instead: each skill is a folder with a `SKILL.md`, plus `references/` and `scripts/`.
